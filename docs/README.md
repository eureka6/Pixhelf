# 使用指南

先按 [Docker 部署教程](../README.md#部署)完成安装，再按下面三步开始使用。

## 第一次使用

1. **创建账号**：在浏览器打开 `http://服务器IP:3002`，按提示创建管理员账号，密码至少 15 个字符。在自己的电脑上安装时，打开 `http://localhost:3002`。
2. **添加照片**：点击「更多（⋯）→ 上传图片」，选择图片，再点「开始上传」。视频和大量照片可直接放入部署时的 `pic` 文件夹；如果改过配置，就放入自己指定的照片目录。
3. **开始浏览**：新文件会自动出现在图库中。首次导入需要后台处理，完成后即可用中文描述搜索图片。

## 常用操作

| 想做什么 | 怎么操作 |
| --- | --- |
| 看照片、视频 | 点开缩略图，放大查看或播放 |
| 用文字找图 | 进入「图库」，点击放大镜，输入「海边日落」「草地上的猫」等描述，再点「搜索」 |
| 用图片找图 | 点击放大镜 →「以图搜图」，选一张图片，查找图库中的相似图片 |
| 收藏喜欢的内容 | 选中图片、视频或相册后点击「收藏」，以后从「收藏」中查看 |
| 保存到电脑或手机 | 打开内容后点击「下载」；多选后可批量下载 |
| 修改密码 | 点击设置齿轮 →「账号安全」 |
| 让别人免登录浏览 | 设置 →「访客模式」→ 开启「免登录浏览」，再把图库网址发给对方；访客可查看、搜索和下载公开内容 |

## 遇到问题

- **图库是空的**：确认文件放进了配置中的照片目录，稍等片刻再刷新页面。
- **中文搜索还不能用**：首次导入需要处理图片，完成前可先按文件名搜索。
- **找不到上传入口**：先登录管理员账号；网页上传每次最多 100 张图片，每张不超过 50 MB。视频请直接放进照片目录。
- **网页打不开**：先检查服务器地址和 `3002` 端口是否可访问，再按[访问排查步骤](DEPLOYMENT.md#访问与排查)查看容器状态和日志。
